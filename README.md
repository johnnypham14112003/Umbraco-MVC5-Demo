# About

This project repository is a source code using ASP .NET Web Application (NET Framework) for demo intergrating Umbraco over a normal MVC5 Project.

- **Version:** .NET Framework 4.7.2

# Package

- [UmbracoCms](https://www.nuget.org/packages/UmbracoCms/7.9.0) `7.9` *(For manage admin Content)*
- [Our.Umbraco.Vorto](https://www.nuget.org/packages/Our.Umbraco.Vorto/1.7.1) `1.7.1` *(For multilingual in Umbraco)*
- [EntityFramework](https://www.nuget.org/packages/EntityFramework/6.0.0) `6.0.0` *(For connecting To Database)*
- [AutoMapper](https://www.nuget.org/packages/AutoMapper/3.3.1) `3.3.1` *(For mapping data from object classes)*
